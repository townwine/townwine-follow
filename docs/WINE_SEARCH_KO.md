# 해외 와인 상품명 검색

## 고객 흐름

국가별 와인 견적 페이지의 ‘해외 와인 검색’ → 상품명, 선택 빈티지, 판매 국가 입력 → 가격 낮은 순 판매처 목록 → 외부 판매처에서 재고·배송 조건 확인.

주소: `/apps/townwine-follow/wine-search`. Shopify app proxy 서명을 검증한 뒤 HTML을 반환한다. 자바스크립트 없이 GET 폼으로 검색되며 모바일 화면을 지원한다. 빈티지 공란은 전체 연도, NV는 논빈티지다. 판매국가와 한국 배송 가능 여부는 다르다. 소매(R), 병(B) 조건을 요청하되 용량이 서로 다를 수 있어 용량을 함께 표시한다. USD로 요청하며 응답이 확인한 통화만 표시한다. 배송비·세금 포함 총액이나 실시간 재고를 보장하지 않는다.

## 데이터 연동

공식 문서: https://www.wine-searcher.com/trade/ws-api (2026-10-09 확인).
Market price API가 판매처·가격·국가·용량·링크를 제공한다. 문서에는 실제 Base URL 대신 `<API Base URL>`만 표시되므로 주소를 추측하지 않는다. 발급된 **Market price API**의 주소와 키가 필요하다. PRO 회원권과 API 계약을 혼동하지 않는다.

서버 환경변수:

- `WINE_SEARCHER_API_URL`: 공급자가 발급한 HTTPS API Base URL. 쿼리 문자열 없이 입력. wine-searcher.com 또는 그 하위 도메인만 허용.
- `WINE_SEARCHER_API_KEY`: 서버 전용 비밀 키. 브라우저/저장소에 넣지 않는다.
- `WINE_SEARCHER_ENABLED=true`: 실제 응답 검증 후 활성화. 기본 비활성.

이 구현은 공식 필드명을 바탕으로 작성했고, 실계정 응답은 아직 받지 못했다. 공개 문서에 JSON 래퍼 구조가 없어 중첩 래퍼를 탐색하되 `return-code`, `list-currency-code`, `merchant-name`, `price`, `link` 등 명시된 필드만 인식한다. 필드가 맞지 않는 응답은 빈 결과로 숨기지 않고 오류 처리한다. 테스트용 응답은 구조 검증용이며 실제 판매 데이터가 아니다.

## 운영 전 남은 검증

1. API 계약/체험 권한과 발급 Base URL을 확보한다. 데이터 표시·보관·출처 표기 조건을 확인한다.
2. 환경변수를 스테이징에 설정하고 성공, 결과 없음, 여러 상품 일치 응답을 실제 API로 확인한다. 필요하면 응답 파서를 실제 계약 스키마에 맞춘다.
3. 판매 링크, 통화, 빈티지, 병 용량을 공급자 원본과 대조한다.
4. 호출량 제한을 계약 할당량에 맞춘 뒤 운영 환경에서 활성화한다.

현재 10초 타임아웃, 2MB 응답 제한, HTTP 리다이렉트 차단, 프로세스당 분당 20회/동시 4회 제한, 동일 조건의 진행 중 요청 합치기를 적용했다. 자동 재시도나 결과 영구 저장은 하지 않는다. 이 제한은 단일 프로세스용으로 일일 계약 한도를 보장하지 않는다. 여러 인스턴스로 확장하려면 공유 호출량 제한이 필요하다. 사용자 오류 화면에 키나 요청 URL을 노출하지 않는다.

API가 없으면 검색 준비 중 안내와 비활성 버튼을 표시한다. 임의 판매처나 샘플 가격은 고객 화면에 나오지 않는다.
